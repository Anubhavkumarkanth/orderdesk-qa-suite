# Entry-level Data Analyst and QA market research (Bengaluru / India)

Collected 2026-10-24. Verified = I opened the posting and read its text. Recommendation = my judgement.

## What I could and could not reach

- I read 9 fresher-level postings in full (listed below). That is short of the 20-30 target: Naukri, Indeed, Glassdoor, foundit and LinkedIn blocked automated reads, several aggregator pages returned 404/410/403/500, and one Deloitte posting was already filled.
- I also pulled 6,967 postings from 37 public Greenhouse / Lever / Ashby boards and kept the 32 data-analytics and 8 QA-titled roles located in India. These are almost all mid or senior (3-10 years), so I used them only for tool-frequency signal, not as fresher targets.
- Excluded on purpose: the `jobtwine` Lever board. It is an ATS vendor's test board (titles like "Ats Lever Testing", "testing 262"), so its "Junior Data Analyst, 10-20 LPA" is not a real vacancy.
- Not verified: salary figures (self-reported or aggregator estimates, some contradict themselves).

## Larger ATS sample (mostly senior, tool signal only)

32 India data-analytics postings: SQL 25, Python 19, dashboards 18, Tableau 16, statistics 16, Power BI 10, A/B or experiments 10, Excel 8, Snowflake 7, Looker 6. Only one (Razorpay, #3 above) was entry-level.
8 India QA-titled postings: all 3+ years; CI/CD and SQL each in 4, Git in 3. Too few to rank tools.
Web-search snippets (not fetched in full) also describe Selenium + Postman + SQL + Jira as the common 1-3 year QA stack and Selenium/Playwright as a nice-to-have at fresher level.

## Decisions (recommendation, not verified fact)

- Data Analyst flagship: SQL-first, with Python for cleaning and analysis, a dashboard, and an Excel deliverable. Power BI Desktop is not installed on this machine, so no .pbix will be claimed.
- QA flagship: manual test design and defect reports as first-class artefacts, API tests, SQL checks and one browser-automation layer. Playwright is used because it runs here; Selenium appears in more fresher postings, so the README will say the concepts transfer and will not claim Selenium experience.
- Roles to target (evidence-based): Data Analyst / Junior Data Analyst / MIS or Reporting Analyst; QA Tester / Junior QA / Software Test Engineer. Business Analyst postings that need Salesforce or stakeholder management fit less well.
